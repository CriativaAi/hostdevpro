HOSTDEVPRO — BRAND KIT
=======================

Marca: HostDevPro
Símbolo: HDP
Slogan principal: Infraestrutura para quem cria o futuro.
Assinatura publicitária: Não hospedamos apenas sites. Hospedamos ideias.

Conceito
--------
H = Host / infraestrutura
D = Development / desenvolvimento
P = Professional / padrão profissional

Paleta sugerida
---------------
Navy: #071226
Blue: #08A9FF
Electric Blue: #155BFF
Violet: #8B3DFF
White: #FFFFFF

Arquivos
--------
logos/dark/  = aplicações sobre fundos escuros
logos/light/ = aplicações sobre fundos claros
icons/       = ícone HDP para favicon/app

Uso recomendado
---------------
- Fundo escuro: HDP-monogram-gradient + versão horizontal-gradient.
- Fundo claro: versão horizontal-gradient ou versões dark.
- Impressão simples: versões monocromáticas.
- Favicon/app: HDP-icon-512.webp ou HDP-icon-512.png.

Observação
----------
Este kit foi montado a partir da proposta visual aprovada nesta conversa.
Para produção gráfica de grande formato, a próxima etapa ideal é criar o master vetorial (SVG/PDF/EPS) do monograma.
